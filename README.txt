JUJUTSU KAISEN-INSPIRED PORTFOLIO (SEPARATED FILES)

FILES:
- index.html: Main page that loads the separate components
- header.html: Navigation header
- home.html: Hero/home section
- about.html: About section
- education.html: Education cards
- projects.html: Projects cards
- tech.html: Tech stack
- contact.html: Contact form
- footer.html: Footer
- css/style.css: All styling and responsive layout
- js/main.js: Contact form behavior and footer year

HOW TO RUN:
Because index.html loads separate HTML files with fetch(), browsers may block it if you double-click the file.
Recommended:
1. Extract the ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Install the "Live Server" extension if needed.
4. Right-click index.html and choose "Open with Live Server".

CUSTOMIZE:
- Replace Your Name and the school/project placeholders in the component HTML files.
- In js/main.js, replace your-email@example.com with your real email address.
- Internet is needed for Google Fonts.

CONTACT FORM:
The form opens the visitor's default email application; it does not send email directly from the website.
